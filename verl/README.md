# Local `verl` Fork for T3

This directory contains the lightly modified `verl` codebase used by the T3 project.

The main project documentation now lives in the repository root [`README.md`](../README.md). The most relevant project-specific entry points inside this directory are:

- `verl/trainer/main_ppo.py`
- `verl/trainer/ppo/ray_trainer.py`
- `search_r1/`
- `cmd/`
- `preprocess/`

For the original upstream `verl` project, see <https://github.com/volcengine/verl>.
